## Hard interpretation rules
- A completed browser demo is not adoption.
- Source hashes validate bytes, not truth.
- Human approval is not execution.
- A locally generated JSON outcome without participant-origin corroboration is not independent verification.
- One timed case is not general time savings, retention or payer demand.
- A second real case is a separate adoption receipt; a paid/deposit/sponsor receipt is a separate commercial one.
- Leave unavailable fields blank. Do not replace gaps with fluent AI output.
- Report adverse or null results. A failed test can still falsify an important assumption.
